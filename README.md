# SPECTRA

SPECTRA is an experimental computer vision project focused on
real-time camera tracking and interactive visual effects.

## Project Status

🚧 Currently in development.

### Current Version

**SPECTRA v0.1**

- Camera access
- Live video feed
- Canvas overlay system

### Planned Features

- Object detection
- Object tracking
- Position tracking
- Rotation tracking
- Real-time visual overlays
- Mobile camera support

## Technology

- HTML
- CSS
- JavaScript
- MediaPipe
- GitHub Pages

## Goal

Build a browser-based computer vision system that can detect,
track, and interact with physical objects in real time.
